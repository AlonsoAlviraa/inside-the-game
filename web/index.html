How it works

One clock, everything in step

The browser plays the event feed on a single match clock. The pitch, scoreboard, timeline and commentary all read from it, so a goal appears everywhere at the same instant and play pauses for the celebration.

Instant, then smarter

Every key event gets a rules-based caption the moment it happens. When the five-agent room has written and fact-checked its version, the line upgrades in place (marked AI). Cards are never shown before the event they describe.

Grounded

LLM text must pass a numbers check, a semantic claim check (leaders, metric names, minutes, periods, possession) and a roster check, with one repair round, or it is replaced by rules text.

Synthetic & brand-free

All clubs, players, crests and matches are generated. No real competitions, clubs, people or logos.

Microsoft stack

Microsoft Agent Framework workflow, Azure OpenAI gpt-4.1-mini (cheapest available), MCP tool server, OpenTelemetry traces, Azure Container Apps.

Cost

A token budget keeps the room under quota; the live cost meter typically shows about one cent per match.
