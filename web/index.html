How it works

The browser plays the event feed on one match clock: pitch, score, timeline and feed always agree. Each key event gets an instant caption from the data; the five-agent AI room (Ingest → Interpret → Explain → Render → Personalise, Microsoft Agent Framework on Azure OpenAI gpt-4.1-mini) rewrites it in place once its version passes the numbers, claims and player checks (✦).

Who it's for

  • Broadcasters' second screen: one event feed turns into three personas (fan, neutral, analyst) in three languages (English, Spanish, French) at once, with no extra commentators.
  • Blind and low-vision fans: 🗣 audio description reads kick-off, shots, cards, subs and highlights aloud; key moments go to screen readers; full keyboard control and a colour-blind palette.
  • Small leagues with no commentary team: any match with an event feed gets live captions, a tactical read and a full-time report. Without AI it still works from data alone.

Measured on our own 45 full-match AI runs (evals/impact_metrics.json): about $0.01 of AI per match (max $0.017), 40 model calls per match, agent time p50 2.9 s / p95 13.8 s per batch (the instant data caption shows first, so nobody waits). A model-free check of 977 AI cards against the raw event feed finds 0 contradictions in 2,155 checks, after fixing the one stale-score bug it first caught (evals/grounding.json).

Safety & limits

Per-IP rate limits and a daily AI spend cap fall back to replay or data-only commentary. Questions pass a prompt-injection guard. Every Ask answer is checked by a critic agent that re-derives the numbers through tools; rejections show in the trace.

Synthetic & brand-free

All clubs, players, crests and matches are generated. Win probability uses a simple Poisson model on score, time left and xG. Hosted on Azure Container Apps; about one cent of AI per match.
